# Giới thiệu
- Đây là dự án được tham khảo từ bài báo "HSEvo: Elevating Automatic Heuristic Design with Diversity-Driven Harmony
Search and Genetic Algorithm Using LLMs" (xem thêm tại README.md).
- Mục tiêu của dự án là re-produce kết quả của bài báo
- Kết quả được lưu tại outputs\, trong đó bao gồm kết quả 3 lần chạy thuật toán HSEvo trên tập problems TSP_ACO
- File "Diversity_analysis.ipynb" là kết quả dưới dạng biểu đồ thể hiện chỉ số SWDI, CDI và Obj Score.
